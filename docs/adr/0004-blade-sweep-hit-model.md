# 飞刀判定改为「扫掠线段」，命中不再由相对速度决定

判定体从「刀尖一个点」改成「圆心→刀尖的线段，外扩 0.18 半宽」；同一把刀对同一只以骸的再次命中间隔固定为转满一圈 `2π/ω`；相对速度 `ω_rel` 从「决定能不能命中」降级为「伤害倍率 0.8–1.3」。`BattleWorld.UpdateBlades` 与 `DamageRules` 是唯一落点。

## 背景

2026-11-01 真机试玩反馈「手感一般」。查下来不是调参问题，是两个结构性缺陷：

1. **贴身完全打不到**。刀尖是点，与以骸圆（半径 0.5）相交的可命中范围只有距离 1.7–2.7 那条 1.0 单位宽的窄环；而尾灯、撞针每 tick 直冲玩家中心，玩家与以骸之间又没有碰撞体积，于是以骸会压到距离 ≈0——既不挨打，也不掉血。设计稿说的「把敌人压在环上」在代码里没有任何机制负责压住它。
2. **命中间隔会爆炸**。旧口径 `间隔 = 2π/|ω_rel|`，而 `ω_rel = ω + s·(m·t̂)/r`：玩家侧向移动 4.8 时 `ω_rel` 可以掉到 0.32，单刀对该敌冷却 19.6 秒；两次移速成长后（5.6）更会撞上 `ω·R = 5.5` 的共振点，冷却 139 秒。玩家看不到任何提示，只会觉得「打着打着突然不掉血」。

同一份数值表下，玩家会觉得「打不中还挨打」，而规则本身没错——错的是判定口径。

## 决定

- **判定体**：`BladeRing.Covers` 用点到线段距离，半径 = 以骸半径 + 刀半宽 0.18。以骸在环内任何位置都会被扫到，包括站在玩家身上。
- **命中间隔**：`DamageRules.BladeHitIntervalTicks(ω)` = `2π/ω`，只与转速和刀数有关。走位不再影响「能不能打中」。
- **走位收益**：`DamageRules.RelativeDamageFactor(ω_rel, ω)` = `clamp(ω_rel/ω, 0.8, 1.3)`。顺着刃口切向走最多 ×1.3，逆着走 ×0.8。正反切仍有用（把顺扫侧拨到人多的一侧），但不再是唯一解。
- **规划器同步**：`LexPlanner` 的命中代理从「环带 + 相对角速度积分」改为「环内即命中 × 倍率」，避免她按旧模型走位。

## Considered Options

- **只加反馈、不动判定**（顿帧/震屏/伤害数字）：否决。反馈再重，打不到还是打不到。
- **完全删掉相对速度**：否决。招牌丢了，改动量和保留倍率差不多，而倍率不引入死区。
- **给以骸加「停在环半径」的行为**：否决。要改模拟层、要重做确定性基线，成本最高，而且不解决第 2 条（冷却爆炸）。
- **加击退把以骸推出内圈**：否决。与 ADR-0003 冲突——击退会在模拟层加第二个位移源，相对速度与确定性断言一起失效。

## Consequences

- `LevelProbe` 的基线变了：L1 从 21477 tick 降到 6227 tick（约 1.7 分钟），L2 7683 tick；两关仍确定性通关，kills 159/159 不变。
- ADR-0003 依然成立：顿帧、震屏、闪白、伤害数字仍然只活在 `BattleRunner`。这次新增的命中顿帧（2 帧、限频 0.12s）同样只改表现层，模拟不感知。
- 设计稿 §4.2 已按本 ADR 改写；`game-design.md` 里「伤害与相对速度成正比」的说法不再成立，勿再引用。
