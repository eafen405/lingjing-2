## 0. 一句话

横屏俯视像素风：操纵邦布「伊埃斯」在空洞里用环绕的飞刀切开以骸，**走位决定刃口的相对速度**，Fairy 代行让你短暂交出控制权、看她自己打。

## 1. 平台与范围

| 项 | 决定 |
| --- | --- |
| 引擎 | Unity 2022.3.62f2（中国版 c1） |
| 目标 | Android APK，真机验收 |
| 屏幕 | 横屏；PPU 32；基准 960×540，整数倍缩放（1080p = 2×） |

## 2. 核心循环

```
进入关卡 → 清空一节（45 个以骸）→ +1 天赋点
        → 击杀累积经验 → 满阈值暂停，三选一（攻击力 / 刀数上限 / 角速度 / 移速）
        → 重复 4 节 → 第 4 节 Boss → 通关解锁下一关
死亡 → 从本关开头重来；关内成长清空；天赋点与已点天赋保留
```

两关共用的是**天赋点**；关卡内的经验等级每关独立，进新关从零累积。天赋在每次进入关卡前可以**重新加点**。

## 3. 操作

| 输入 | 位置 | 作用 |
| --- | --- | --- |
| 移动摇杆 | 左下 | 360° 移动 |
| 技能键 | 右下 | 满槽释放 **Fairy 代行** |
| 正反切键 | 技能键上方 | 翻转飞刀环绕方向 |

手机三输入，右手拇指一个技能键 + 一个切换键，不跨屏。

## 4. 战斗

### 4.1 飞刀环

- **外圈**：初始 4 把，均匀分布；半径 2.0；角速度 ω。
- **内圈**：半径天赋第 3 级开启；半径 = 开启瞬间外圈的 0.6 倍并锁死；刀数 = 开启瞬间外圈数量的一半；方向与外圈相反；**不磨损**。
- 两圈同步受正反切影响。

### 4.2 伤害模型：DPS 与相对速度成正比

```
每秒命中刀数 = N · |ω_rel| / 2π
ω_rel = ω + s · (m · t̂) / r
```

- `s` 是旋转方向（正反切的符号），`m` 是角色移动速度，`t̂` 是该敌人所在方位的刀刃切向。
- **顺着刀刃切向移动**时相对速度最大、单位时间命中的刀数最多；逆着走会减少命中。
- 所以专家玩法是：把敌人压在环上，并让移动方向与刃口同向。正反切用来把「顺扫侧」拨到敌人密集的一侧。
- **离散化口径**：不设与 ω 无关的固定命中间隔。同一把刀对同一只以骸的再次命中间隔 = `2π / |ω_rel|`，用命中那一刻的相对角速度算。于是：站着不动时间隔正好是一整圈（每把刀一圈内对同一以骸最多命中一次，转满一圈后重新可以造成伤害）；顺着刃口切向走时间隔变短、逆着走变长；`ω_rel` 趋近 0 时间隔趋于无穷，也就是不再命中。上面那条公式不是另写一遍的近似，而是碰撞判定跑出来的结果。

### 4.3 正反切

- 冷却 = `(2π / N) / ω`，即一把刀走过相邻两刀之间的扇区所需的时间（初始 4 刀、ω = 2.5 时约 0.63s）；随刀数上限与角速度成长而缩短。**无消耗**；不必松开摇杆；两圈同时翻转。
- 冷却不能比这更短：翻转的代价若低于「让一把刀多走一格」的时间，连续翻转就能把刀停在原地，把以骸卡在刀与刀之间反复吃伤害，绕开 §4.2 里「伤害与相对速度成正比」这条规则。
- 翻转后刀刃位置连续、角速度方向取反。

### 4.4 充能

- 击中以骸 +2，击杀 +15（上限 100）。
- 满槽才能释放；释放后清空；**代行期间不回能**。

### 4.5 Fairy 代行（技能）

- 持续 4 秒（待原型验证），期间玩家输入完全屏蔽，Fairy 控制移动与正反切。
- 行为按**优先级栈**，不是权重求和：

| 优先级 | 意图 |
| --- | --- |
| P0 | 不掉血（最高优先） |
| P1 | 敌人留在攻击范围内 |
| P2 | 让相对速度最大化（选移动方向 + 旋转方向） |
| P3 | 顺路拾取：血包（血量 <40% 时最高）> 刀 > 能量球（代行期间权重 0） |

- 约束：Fairy 与玩家共用同一动作空间与同一套数值，不无敌、不加速、不传送——**是熟练玩家，不是外挂**。
- 实现：网格 A* + 候选点采样（敌人/道具/安全位）+ 1 秒前瞻效用评分，每 100ms 重规划。
- 调试叠层：候选点、路径、期望收益可视化，默认关闭，演示/录屏时打开。
- 原型阶段先用简化策略（贪心 + 前瞻），验证手感后再投入算法打磨。

## 5. 以骸

分类词：**以骸**（沿用原著）。Boss 级称**恶名以骸**。

| 名称 | 类型 | 行为 | 出现 |
| --- | --- | --- | --- |
| **尾灯** | 追击 | 持续贴近日标 | 一、二关 |
| **撞针** | 冲锋 | 0.6s 预警后直线突刺，突刺后短暂硬直 | 一、二关 |
| **钉枪** | 远程 | 站定发射慢速铆钉弹 | 一、二关 |
| **坠物** | 空降 | 在目标附近投下矩形警示区，延迟落地 | 仅第二关 |
| **恶名以骸·连环** | Boss | 全程冲锋；血量 ≤50% 后**追加**召唤钉枪（每次 2 只，同屏 ≤4）；冲锋后 1.5s 硬直 | 第一关第 4 节 |
| **恶名以骸·骤雨** | Boss | 小矩形落点，在玩家附近随机分布、**必有一块落在玩家当时的位置**；预警 3s；技能之间有冷却隔断，不叠加释放 | 第二关第 4 节 |

- 敌人移速必须低于玩家移速，否则「不掉血」与「保持射程」无法同时成立。
- 坠物与骤雨的落区一律用**矩形**（像素对齐），不用圆。

## 6. 关卡

| 项 | 第一关 | 第二关 |
| --- | --- | --- |
| 节数 | 4（第 4 节 Boss） | 4（第 4 节 Boss） |
| 普通节敌人 | 45 | 45 |
| 敌人种类 | 尾灯 / 撞针 / 钉枪 | 尾灯 / 撞针 / 钉枪 / 坠物 |
| Boss 节 | 连环 + 8 杂兵 | 骤雨 + 8 杂兵 |
| 差异 | 基础 | 数值提升 + 坠物（封走位） |

清空全部以骸即过关；过关进下一关。

**投放**：一节的 45 只以骸分 3 波 × 15 只投放，每波落在玩家周围 1–2 屏内，清空当前波才投放下一波。一次铺满整张场地会让大半时间花在赶路上，而且钉枪站定不动，清场末尾容易剩下几只搜不到的个体。Boss 节的 8 名杂兵与恶名以骸同时在场。

**推进**：四节在同一张场地上原地依次推进，不换场景、不切房间；节与节之间短暂停顿并提示节号，生命与关内成长连续带到下一节，直到第 4 节的恶名以骸。

场地尺寸：手机一屏是 30×17 瓦片（960×540），但**一屏不等于整张地图**——相机跟随玩家，
一节的场地按 96×54 瓦片（约 9 屏面积）铺，边界围在外圈。地图与场地美术见
`docs/specs/terrain-tileset.md`。

## 7. 成长

### 7.1 关内成长（肉鸽层，每局重置）

- 经验来自击杀，**按以骸强度加权**（不是数人头）；击杀本身就是成长过程。
- 满阈值 → 暂停 → **三选一**，池子四类：

| 选项 | 效果 |
| --- | --- |
| 攻击力 | 每把刀的伤害 |
| 刀数上限 | 外圈上限 +1 |
| 角速度 | ω +X |
| 移速 | 移动速度 +X |

- 已满级的类别退出池子；升级时暂停游戏（含代行计时）。

### 7.2 刀数与磨损

| 规则 | 值 |
| --- | --- |
| 初始外圈 | 4 把 |
| 上限 | 10 把 |
| 上限成长 | 每次「刀数上限」+1，最多 6 次（上限能加几次待美术确认可读性） |
| 磨损 | 每把刀命中 20 次后碎裂，从最旧的一把开始 |
| 磨损底面 | 外圈最低 4 把 |
| 拾刀 | +1 把至上限，拾到的那把耐久回满 |

### 7.3 地面掉落（普通）

| 掉落 | 作用 |
| --- | --- |
| 刀 | 补一把飞刀 |
| 血包 | 回复生命 |
| 能量球 | 回复充能 |

- 走进 0.6 单位自动拾取，不占按键。
- 掉落以敌人掉落为主 + 每节 2–3 个固定补给点；不做地板随机散落。

### 7.4 天赋（永久层）

- 每**首次**清空一节 +1 天赋点（同一节只发一次，防刷）。
- 天赋池 **8 点**，列表式、无依赖、同类可加点：

| 天赋 | 级数 | 效果 |
| --- | --- | --- |
| 半径 | 3 | 外圈半径提升；第 3 级开启内圈 |
| 初始充能 | 2 | 开局 40% / 80% |
| 移速 | 1 | +10% |
| 角速度 | 1 | +10% |
| 攻击力 | 1 | +20% |

- 每次进入关卡前可以**重新加点**，不消耗资源。
- 两关合计 8 节 = 8 点，正好点满池子。

### 7.5 暂缓

- 暴击率 / 暴击伤害：ADR 原文列了，v1 不引入（纯增加复杂度），之后再评估。
- 多邦布与不同邦布的充能技能：v1 只有伊埃斯。

## 10. 美术

视觉上分两层，**这个反差是刻意的，不要统一**：

- **世界层**：像素 32×32 单位、PPU 32。场地、以骸、伊埃斯、飞刀、道具按像素规则画，统一色板与描边。
- **Fairy 层**：叠加在世界层之上的高分辨率界面——Fairy 的气泡、全部 UI（主菜单、HUD、三选一、结算）、提示与警示。它不是像素风：Fairy 是凌驾于空洞之上的存在，界面比世界更锐利、更亮、更像一块工业屏幕，这个落差就是她的位置感。视觉语言与取色见 `docs/agents/fairy-visual.md`。

素材由对应的 AI agent 绘制（ADR 要求），世界层统一色板与描边规则。清单见 §10.1。

## 附录 A 原始设定（原文）

> 2026-10-29 作者原文，保留不改写。上文是它的收敛结果；两者冲突时以上文为准。

这里关于玩法的文档。我们要使用unity做一个小游戏。要求安卓端apk需能正常体验。
1. 飞刀旋转小游戏，飞刀可以绕着主角旁边旋转。每个飞刀有可以成长的**攻击力**（atk）数值，可以成长的**角速度**（omega）数值，可以改变的**旋转半径**（radius）.同时有**暴击率**，**暴击伤害**等可提升的数值。每种飞刀的基础数值不一样。
2. 主角是伊埃斯（或者其它邦布），没错，是绝区零中的伊埃斯，为什么能让飞刀旋转呢，Fairy可以解释（没错，III型总序式集成泛用人工智能）（部分素材在https://github.com/eafen405/OurFairy，基本与本项目无关），理由还没想好，待会儿再想。有什么数值：**生命值**（hp）,**充能值**（energy）,充能值根据邦布的不同，会有不同的技能。生命值不同的基础值，而且会随着成长而提升。**飞刀上限**，环绕的飞刀的最大数量。**移动速度**（speed）,不用解释。
3. 整个场景使用像素风，除了Fairy的提示气泡。素材需要由对应的AI agent进行绘制。
4. 世界观，就是探索空洞，基于绝区零世界观的二创小游戏。
5. Fairy的台词语音使用gptsovits合成。已有模型权重与提示语音段。
