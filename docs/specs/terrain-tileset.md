# 空洞地形规格：边界、障碍与传送门

> 规格状态：定稿（2026-10-31）。上游：`docs/design/game-design.md` §6/§10；任务：`docs/plan/backlog.md` T22。
> 本文只定「长什么样、怎么命名、怎么拼」，不定画法；画法在 `tools/art-pipeline/terrain_draw.py`。

## Problem Statement

地形原本只有一句约束：「32×32 瓦片 + 共用色板」。但这句话会引出一套铺装：
地板变体、砖缝、边缘、贴花、墙脚投影……素材量远超一场横屏竞技场真正需要的量。
更要紧的是，空洞的世界观本身就是「外面什么都没有」，把地面画满铺装反而会让
画面比玩法更吵，也让白色伊埃斯和深色以骸在同屏里更难分。

## Solution

**不做地板、不做背景色。** 场地内部留空，由相机清屏色决定；地形只负责三件事：

1. 用一圈**边界墙**围出可活动范围；
2. 用**挡路物**切走位、给 A\* 生成障碍格；
3. 用**传送门**标出「下一节 / 出入口」。

这套做法把地形素材压到 14 张，且不再需要「地砖拼接是否无缝」这类问题。

## 素材清单

| 类别 | 文件 | 尺寸 | 数量 | 精灵锚点 |
| --- | --- | --- | --- | --- |
| 边界墙 | `wall/wall_{n,e,s,w,nw,ne,sw,se}.png` | 32×32 | 8 | 瓦片（Tilemap 单元） |
| 挡路物 | `props/prop_crystal.png`、`props/prop_block.png` | 64×64 | 2 | 底边中心 (32, 0) |
| 传送门 | `portal/portal_{00..03}.png` | 96×96 | 4 帧 | 底边中心 (48, 0) |

- 图集：`wall/terrain_wall.png`（一行 8 格）、`portal/terrain_portal.png`（一行 4 帧）。
- 传送门 10fps、循环；它不是瓦片，是场景里的实体，带碰撞体与触发区。

## 尺寸为什么是 64 / 96

伊埃斯在 PPU 32 下高 56px（1.75 世界单位），以骸 44–54px。地形物件若按 32×32 画，
撑满也只有半个角色高，站在旁边会被读成地上的花纹而不是挡路的实体。
所以障碍给 64（2 单位）、传送门给 96（3 单位），与角色同量级。

## 拼接契约

- 边界墙用 4 位掩码确定朝向：`n=1, e=2, s=4, w=8`；瓦片名直接对应掩码组合。
- 每块墙只画「真正朝外的那一侧 + 它的对面」：全画四边会退化成网格。
  外沿按光照分亮（N/W）暗（S/E），内沿留 1px 转折。
- 场地由一层 Tilemap 铺 `wall` 瓦片围成一圈，中间不铺任何瓦片（`floorTile: null`）。
- 挡路物的碰撞体建议 32×32 或 64×32，与视觉轮廓对齐但不含透明边。

## 命名与元数据

`Assets/_Project/Art/Terrain/tileset.json` 是程序读取的唯一来源，含：

```
tileSize / ppu / edgeMask / walls[{name,mask,file,atlas,cell}]
props[{name,size,pivot,file}] / portal{frameSize,pivot,frames,fps,loop,atlas,pattern}
palette{名称->hex} / floorTile: null / background: null
```

## 色板口径（撤销「全项目 32 色」上限）

原规格 §4 的「32 色（含透明）」是上一轮会话自定的预算，不是考核要求。
角色素材已用掉 29 色并冻结，为凑数字去改已验收的图不划算。**现在改为：**

- 角色 29 色是主色板，不动；
- 地形新增 14 色（8 个冷灰蓝阶 + 6 个传送门洋红/青），全部登记在
  `terrain_draw.TERRAIN_COLORS`，并写入 `tileset.json`；
- 新素材允许新增色，但必须登记在对应模块的色板常量里，不允许散落在绘制代码中。

## 验收

1. 尺寸与锚点符合上表；边界墙整块不透明，障碍/传送门保留透明边。
2. 只用登记的色板；alpha 只有 0 或 255；无抗锯齿。
3. 边界墙任意拼接无错位、不回头（外沿亮暗方向一致）。
4. `tools/art-pipeline/out/terrain_room.png`（合成场地，透明底）里，100% 缩放下
   白色伊埃斯与四种深色以骸都可凭剪影辨认。

## 明确不做（原 T22 验收里的两项）

| 项 | 处置 | 原因 |
| --- | --- | --- |
| 地板瓦片 | 取消 | 用户要求「不需要网格、不需要背景色」，场地内部留空 |
| 门 | 暂缓 | 没有墙体门户的场景，门只是装饰；出入口统一用传送门 |

墙脚投影、贴花、天穹与城市剪影同样不做。
