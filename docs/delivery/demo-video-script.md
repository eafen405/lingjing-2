# 实机演示视频 · 分镜

> 你自己录。目标时长 3 分钟左右，一次录完不剪辑也可以；重点是让验收方在 30 秒内看懂循环。
> 录之前：`adb install -r Build/Lingjing.apk`，把手机调成横屏、开免打扰、清掉通知。

## 录制前的一次性准备

- [ ] 装最新 APK（`Build/Lingjing.apk`）
- [ ] 先玩到通关第一关一次，确认「第二关已解锁」这个状态存在（验收点靠它演示）
- [ ] 打开系统录屏，麦克风可选（有解说更好，没有也能过）
- [ ] 手游常见问题：录屏时通知弹窗会进画面，先开免打扰

## 分镜

| 时间 | 画面 | 要点 |
| --- | --- | --- |
| 0:00–0:10 | 主菜单 | 停留 2 秒，让「关卡选择 / 开始」看清 |
| 0:10–0:20 | 关卡选择 | 第一关可点、第二关灰显「未解锁」——这是存档验收点 |
| 0:20–1:10 | 第一关第 1–2 节 | 走位绕环、正反切把刃口拨到人多一侧；故意贴脸打一只，证明贴身的怪也掉血 |
| 1:10–1:25 | 三选一 | 击杀攒满经验后暂停弹三张牌，选一张，说一句选了什么 |
| 1:25–1:45 | Fairy 代行 | 充能满 → 点技能键 → 画面出现 Fairy 徽记、角色自己走位 |
| 1:45–2:20 | 打到第 4 节 | 恶名以骸登场（顶部有长血条），打掉它 |
| 2:20–2:35 | 通关结算 | 得分 / 最高分；回主菜单 |
| 2:35–2:50 | **杀进程重开** | 划掉进程 → 重新打开 → 关卡选择里第二关已解锁（重启后存档仍在） |
| 2:50–3:10 | 第二关 | 只需展示 30 秒：坠物落区、更密的敌人 |
| 3:10–3:20 | 收尾 | 回主菜单，结束 |

## 旁白台词（可选，照着念）

- 开场：「这是个飞刀环绕的像素动作游戏，两关，一局八到十二分钟。」
- 关卡选择：「第二关还没解锁，通关第一关之后会一直保持解锁。」
- 战斗：「飞刀绕着角色转，贴身也能打到；顺着刃口方向走伤害更高。」
- 代行：「充能满了可以让 Fairy 接管，她自己会走位打人。」
- 结算后：「杀掉进程重开，解锁状态还在。」

## 常见翻车点

- 录屏分辨率太高导致卡顿：用 1080p / 30fps 就够。
- 中途断了重录会多花时间：先把第一关打通一次再开录，避免录到一半发现达不到 Boss。
- 竖屏锁定：游戏是横屏，进游戏前先关掉系统竖屏锁定。
